# Third-party notices

## Body map anatomical illustration (src/lib/bodyMapData.js)

The muscle-region and body-outline path data in `src/lib/bodyMapData.js`
is adapted from the `react-native-body-highlighter` npm package's SVG
path data (front/back male body art), re-exported for a plain web
`<svg>` with no react-native dependency. Only the raw path coordinates
were kept — no code from the original package is used.

Source: https://www.npmjs.com/package/react-native-body-highlighter
